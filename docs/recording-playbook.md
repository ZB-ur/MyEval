# 真实录像与操作 playbook

`scripts/build-playbook.py` 将已经记录的浏览器/应用录像整理为离线中文操作参考。它读取片段与章节清单，从原片提取 PNG，生成章节导航、视频播放器、操作说明、原片 hash 和证据索引。它不录制视频、不合成替代视频、不把既有截图变成录像，也不自动补写未经记录的观察结论。

历史产品原始视频、截图、清单和生成页面均放在被 Git 忽略的 `.local/recording/`。当前仓库另提供由虚构办公演示生成的[图文操作指南](walkthrough.md)和 `docs/assets/` 截图，不包含历史模型输出。不要录入管理员访问码、模型凭据或未经授权的资料；工具的字段清理不能替代录制前控制画面范围。

## 清单格式

建议使用 `segments.json`：

```json
{
  "title": "MyEval 操作参考",
  "description": "真实操作原片、关键帧与逐项证据。",
  "coverage": {
    "status": "partial",
    "note": "覆盖本次浏览器操作；后台源码阅读与命令执行另有日志。"
  },
  "timestamp_note": "墙钟标记相对录像起点的误差在一秒以内，不作为帧级同步。",
  "segments": [
    {
      "id": "01-baseline",
      "title": "原版盘点",
      "path": "raw/browser-01.webm",
      "started_at": "2026-11-18T03:38:33.385Z",
      "ended_at": "2026-11-18T03:43:09.029Z",
      "complete": true,
      "recording_note": "独立浏览器窗口的连续录像，无麦克风。",
      "limitations": ["不包含后台开发过程。"],
      "chapters": [
        {
          "at": "2026-11-18T03:39:10.714Z",
          "frame_at": "00:39.500",
          "title": "查看实验列表",
          "url": "http://127.0.0.1:8329/",
          "note": "本次使用明确标注的隔离材料。",
          "steps": ["打开工作区。", "选择目标项目。"],
          "expected": "只显示该项目的实验。",
          "observed": "由实际操作者填写已观察结果。",
          "recovery": "若列表未刷新，记录现象后重新载入。",
          "evidence": ["exports/example.zip", "observations/example.json"]
        }
      ]
    }
  ]
}
```

- `path` 相对 `segments.json` 所在目录，也允许明确的绝对媒体路径；只处理 `.webm`、`.mp4`、`.mov`、`.mkv`、`.m4v`。实际解码支持取决于 FFmpeg。原片只读。
- `started_at` / `ended_at` 为带时区的 ISO 时间；不要用文件修改时间冒充录像起点。`complete: true` 且有 `ended_at` 才显示“已闭合原片”；有结束时间但未声明完整则显示“部分片段”。没有结束时间的在录文件不读取、不计算 hash、不提帧。
- 若结束墙钟只是操作者事后粗记或文件修改时间推定，保留原值并设置 `ended_at_estimated: true`。页面会将结束时间和墙钟跨度标为估计；不能从媒体时长反造精确停录墙钟。若章节点本身为推定值，设置 `at_estimated: true`，目录与步骤时间显示“约”。
- `coverage.status` 为 `complete` / `partial` / `unknown`，描述整个交付所覆盖的范围；片段闭合不自动证明整个研发过程全程录制。工具同时列出片段之间的未录制间隔。若区间中存在起点墙钟未知的部分原片，则单列为 `unmapped_intervals`；区间跨度不是未录制时长，不计入 `unrecorded_intervals` 总量。相对视频时间仍可用于章节与关键帧定位。
- 章节 `at` 支持带时区 ISO 时间、片段内秒数（如 `37.329`）或 `HH:MM:SS`。ISO 章节依据 `started_at` 映射，不推测更精细的同步精度。
- 可选 `frame_at` 使用同一时间格式，单独指定值得保留的画面时刻。例如 `at` 标记点击按钮，`frame_at` 标记稍后结果加载完成。目录与“定位此步骤”始终跳到 `at`；仅关键帧使用 `frame_at`。没有提供时沿用 `at`。索引分别保存原始 `at`、`seconds`、`frame_at`、`frame_requested_seconds` 和提帧定位点 `frame_seconds`，明确画面与操作起点可能不同。请选择真实看过的原片时刻，不用修改时间掩盖等待或失败。
- 已有录像的章节点也可能在动作完成后才标记。保留原始 `at`，按实际原片选择更早的 `frame_at`，在 `observed` 说明二者关系。若画面未显示预期页面，应记录可见的失败状态，不将旁路日志或截图当作该章的原片证据。
- 显式空章节数组保持为空，不自动补造“片段开始”或关键帧。该段仍显示在目录与原始证据区，可直接打开原片；中断片继续保留 partial。
- `steps` 也接受 `step`；`recovery` 也接受 `error_recovery`；`evidence` 也接受 `evidence_paths`。缺失的步骤、预期、观察、恢复会明确显示待补充。
- 页面 URL 仅作说明，查询参数会去掉；带账号信息或可识别秘密的 URL 不输出。证据路径只显示，不扫描或打包对应文件。只复制显式选择的原视频（若启用复制）与提取帧。

工具兼容顶层 `segments: [...]` 的对象或直接片段数组。外部 `chapters.json` 支持 `[{"at": "...", "title": "...", "url": "..."}]` 或 `{"chapters": [...]}`，默认读取同目录文件。相同 `at` 与 `title` 的内外章节去重，以片段内记录为准。多片段的相对时间章节须填写 `segment_id`；ISO 时间按起止区间归属，无法归属的章节明确报告。

## 生成与打开

Python 标准库即可运行；视频解码需要 FFmpeg。默认从 `PATH` 查找 `ffmpeg`，也可使用 `--ffmpeg` 指定完整路径。先关闭并保存录像，再生成：

```sh
python3 scripts/build-playbook.py .local/recording/20261118/segments.json \
  --ffmpeg /path/to/full/ffmpeg \
  --output-dir .local/recording/20261118/playbook
```

直接在浏览器打开输出目录中的 `playbook.html`。页面无远程字体、CDN、分析脚本或网络 API；可离线使用。默认通过相对路径引用原片，移动目录时要保留相对结构。需要独立搬运时增加 `--copy-videos`，视频复制到输出目录 `media/`，副本与原片 SHA-256 相同。不会覆盖原片，也不允许把输出放进原片 `raw/` 目录。

“下载证据索引 JSON”从页面内嵌的索引生成本地 Blob 下载，避免离线 `file://` 链接只打开文件而未触发下载。下载内容与磁盘索引的字段一致；JSON 数字或空白的序列化格式可能不同，因此导出文件自身 hash 不必相同，索引记录的原片、清单和关键帧 hash 保持不变。

每次生成会更新 `playbook.html` 和 `evidence-index.json`；帧及可选视频副本使用内容 hash 命名。原片、清单和提帧工具的 SHA-256、媒体时长、墙钟跨度、标记时间与提帧定位点都进入索引。末尾标记超过可用最后一帧时采用邻近末帧，并明确注明；失败则显示缺口，不换用其他截图。原片在生成期间发生增长或修改会使生成失败，需结束录制后重试。

原始章节点若超过实际视频时长，工具会保留该标记并明确警告；播放器最多定位到原片末尾。关键帧可以独立选择有效时刻，但这不能修复或掩盖原始时间标记的不准确。完整解码只证明媒体可读取，不能把关闭回执缺失的 partial 片段改称完整过程录像。

章节导航支持搜索与定位；视频播放时随时间切换说明。桌面目录固定在左侧，窄屏改为上方可滚动目录。播放器保留浏览器原生播放、进度、音量及全屏控制。可用键盘操作，焦点可见。
