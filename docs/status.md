# MyEval 当前状态

2026-11-25，V2.0.0 集成版本。用户已确认保留的界面基线与 V2 执行、评分、数据、导出模块归入同一源码版本；当前界面规范见 [DESIGN.md](../DESIGN.md)，发布操作与验收见[本次记录](acceptance/2026-11-25-release.md)。

## 本版本包含什么

- 同一材料比较 2–16 个配置，冻结案例、参数与来源，保留每次尝试及失败。
- 版本化数据集、独立 AI 评分队列、匿名评阅、家族统计、质量判定和完整导出。
- SQLite 与文件证据备份，可恢复到新的独立目录；本机管理员访问码与匿名席位分开。
- 当前桌面与移动界面，以及无需产品源码、模型或凭据的虚构办公演示。
- Sijian、pomegranagent-v2、Sidelit 的真实产品适配器；产品本体和模型环境另行准备。

核心服务只监听本机，当前实测环境为 macOS / Python 3.14.3。代码要求 Python 3.11+；本机锁与进程管理依赖 POSIX，Windows 未验收。核心没有额外 Python/npm 运行依赖；可选 Langfuse 观测栈与录屏解码工具另行安装。

## 哪些结论仍有边界

本次版本整合与演示不产生新的产品质量结论。三项目的历史实测仍见 [2026-11-18 验收](acceptance/2026-11-18-platform-v2.md)：Sijian 候选有双 AI 裁判支持；Pome 候选的 token 节省未证明质量非劣；Sidelit 后续无分数候选未过门槛。真人评价、真实儿童、物理 iPhone、生产效果均未据此得到证明。

当前界面已由用户选择保留，历史 UI5/UI6 的评分不移植到当前界面。企业权限、多租户、分布式执行、在线 A/B、自动红队与任意 GUI 产品的无人值守闭环仍未实现；详见[能力范围](architecture-v2.md)。

GitHub 源码只包含运行程序、虚构任务包、量表、文档与演示截图。实际产品运行输出、账号、私有数据、模型权重及历史录像不随仓库发布。过去各日期的状态保存在[历史记录](status-history.md)，其中的端口、进程和未完成事项不能当作当前状态。
