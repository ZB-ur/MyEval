2026-11-25。本版将 MyEval 作为独立评测平台按 MIT 许可开放源码，补齐外部使用者的 README、能力矩阵、三项目案例和图文操作手册。没有新增真实业务模型评测，没有改动三个外部产品或改变其默认方案。V2 核心整合验收仍见[此前记录](2026-11-25-release.md)。

- [图文 playbook](../walkthrough.md)：从启动到恢复备份，新增 11 张实际界面截图；保留原有桌面、匿名评审和窄屏配图。
- [能力矩阵](../capabilities.md)及[真实项目案例](../playbooks/real-projects.md)：区分直接支持、需准备的环境与尚未覆盖的场景；案例含配置、数量、方法图、历史结果及不采用的理由。

## 新增实际操作

环境为 macOS、Python 3.14.3、Chromium 159。使用独立源码副本、空数据目录和端口；材料全部取自原创虚构办公演示。

| 操作 | 实际观察 |
| --- | --- |
| 首次启动演示 | 1 个实验，18 项运行，15 成功、3 个明确的附件缺失故障；无需产品源码或模型凭据。 |
| 浏览器建立实验 | 选择会议安排与上线计划，以原文摘要为基线、另两种为候选，先建立并暂停，再恢复和刷新；6/6 成功。 |
| 独立评分配置 | 实际打开评分器、量表、配对及预算表单；预检 4 个配对单元后取消，未提交评分请求。模型实际值仍未知。 |
| 质量判定 | 两家族实验使用明确的演示门槛，未设置质量维度，结果为 `inconclusive`；6/6 执行成功没有变成质量通过。 |
| 备份与恢复 | 浏览器创建 121 文件的备份，清单与逐文件校验通过，恢复到独立目录。 |
| 启动恢复副本 | 实际在新端口启动，2 个实验、24 项运行及原判定仍在；管理员访问码重新生成。恢复不重放产品请求。 |
| CLI 数据集流程 | 导入 1 个不可变版本、2 案例、2 家族，运行三方案得 6/6 成功、6 次尝试，实际并发峰值 1；模型调用、AI 评分及真人评价均为 0。 |
| CLI 导出与持久化 | ZIP 为 76,383 字节，CRC 正常；同内容再次导入为 `unchanged`，停启后实验身份、数据集版本/哈希及运行记录不变。 |

浏览器试跑与 CLI 验收是两套独立工作区，不能相加成一轮独立业务实验。截图中模型评价为 0，是演示的真实边界，不是遗漏了评分数据。

## 文档与公开内容复核

独立审阅核对了三项目配置 ID、任务包版本和开发试跑规模（18 / 24 / 9 / 36 trial），以及历史运行、模型评价与真机边界。四张案例方法图通过 Mermaid 实际解析。来源漂移的表述已明确为“该项失败并阻止产品请求”，没有声称自动暂停整个队列；历史产品默认也按当时状态描述。

公开前对已推送主分支及 v2.0.0 的 5 个提交、184 个不同文件对象进行审阅，未检出高置信凭据、私钥、真实儿童资料或实际模型输出原文。历史中保留普通 Git 作者邮箱及部分旧本机路径，它们属于历史身份元数据。新增截图使用演示数据，真实产品数据库、原始输出、私有材料和模型权重不纳入源码包。

本次新增操作录制为两段已关闭原片，11 个稳定画面标记；与此前三段办公演示录像共同形成[离线操作包](https://github.com/ZB-ur/MyEval/releases/download/v2.0.1/MyEval-v2.0.1-playbook.zip)，共 5 段、23 章/帧、301.20 秒。实际核对章节跳转后视频可播放、无媒体错误；390px 页面无全局横向溢出，搜索“恢复”返回 3 个章节。原片、关键帧及索引使用相对路径并保留哈希。

片段之间有间隔，录制范围是指定浏览器操作，不能称为全部研发过程全程录屏。录像不包含模型质量评分，窄屏录像也不是物理手机验收。公开材料的相对文件与图片引用已全部核对；首页在 1040px 和 390px 的实际浏览器渲染中图片正常、折叠区可用，整页和表格未超出视口。

## 历史结果与当前边界

三项目案例引用已公开的历史汇总，没有读取封存确认集或复算私有原始输出。Sijian 候选的质量支持、pome 的 token 节省但质量非劣未证、Sidelit 的淘汰决定保持各自边界。公开开发材料不能重算历史正式留出集数值；真人意见、真实儿童、物理 iPhone 和生产效果仍未由这些演示证明。

没有新增单元测试、测试目标或断言脚本来替代实际服务与浏览器验收。服务仍是本机单操作者工具；发布源码不等于完成生产部署或团队安全架构。
