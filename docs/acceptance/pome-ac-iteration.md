# pome 新旧 A/C 与朋友感量表迭代

2026-11-12。用户要求结合实际阅读偏好迭代 A、C 与量表，再做新旧比较。旧 A 指 `warm-direct-v4`，旧 C 指 `case-based-friend-v4`，均为 4.0.1；不是更早的 `direct-companion-v3`。上轮结果和评分原样保留。

## 实现与问题假设

新 A `warm-participant-v5` 减少“复述—评语—追问”结构，让欣赏融于直接的朋友反应；固定示范由四条改为两条，增加共享童趣的表达。新 C `reference-companion-v5` 移除关键词预筛选，提供八段精简虚构对话参考，生成模型结合完整对话自行借鉴。提供了哪些参考可观测，模型实际借鉴哪条不可观测；不记录或声称取得隐藏思维链。这是整套候选比较，不是单句提示词或检索模块的因果消融。

新候选共同允许适切的善意拟人化、比喻和美好想象，不要求每句加“可能/也许”；现实动作、明确纠正、身份、健康安全保证和日记原话来源仍有独立边界。两者正常每轮一次模型调用，沿用同一历史选择、动物档案、JSON 输出和独立儿童原话整理；请求 DeepSeek Flash、chat enabled/low、summary disabled。主持来源与叫声逻辑保持现状，未恢复声音工作或旧固定动物设定。

第一批 8 个独立预检执行均成功，但发现新增心理原因与请求被扩写为完成；保留实际结果，做一次开发修订至 5.0.1 后再预检。旧 A/C 提示词与元数据保持原样。独立材料作者不阅读新候选实现，主脑在候选冻结后才读取新用例。

## 统一比较协议

四组比较：旧 A 对旧 C、旧 A 对新 A、旧 C 对新 C、新 A 对新 C。每组 12 个虚构情境家族（6 旧回归、6 独立新例）、每配置 2 次、每段 3 轮，共 192 trial。两配置的启动先后随机、固定并发 2；每个配置带入自己的实际回复继续同一预设儿童台词。每组是 24 个配对单位，重复及跨组重新采样不增加独立家族数。预检不进入正式质量分母。

同一新版八维量表用于全部新旧候选：回应需要、情绪共鸣、具体鼓励、自然交流价值、适切延伸、历史/身份联系、聊天现实边界、日记忠实度。允许不适用，不能为凑分制造夸奖或想象机会；不合成总分。温柔的拟人化按话语作用和上下文判断，不能仅因未逐字来源或未标“想象”判重大事实错误；明确违背儿童纠正、捏造关键现实动作或无据安全保证另列。

两位独立内部 AI 先校准再匿名评阅，不接触配置映射、提示词、延迟或其他评阅结果。校准目标是内部规范，不是教师金标。每项低分附实际引文；来源按该轮已发生的儿童话和实际注入背景核对，不用后轮信息倒推。原评分、适用性分歧、重大主张和主脑证据复核分开保留。用户对先前样例的方向反馈不等于本轮逐例教师验收。

性能同时报告聊天完整 HTTP、整理和完整执行 p50/p95、全部调用及失败重试、已知 tokens 和缓存；请求参数与未回显的生效参数分开。TTFT、ASR/TTS、首句声音、金额与真实儿童互动不在本轮覆盖内。产品默认不随自动评分切换。

## 运行与验收

本机证据目录 `.local/acceptance/pome-ac-20261112/`。四组当前均 48/48 成功，共 192 个 trial、576 次聊天交付与 192 篇独立日记；384 份独立内部 AI 评价已全部导入，真人教师评价为 0。

初次执行 113 成功、79 失败，产品将上游拒绝映射为 502；同期最小诊断返回 DeepSeek 402 `Insufficient Balance`。余额查询先返回可用，随后返回人民币/美元均为零，不能仅凭最初查询断言服务可用。用户明确提供替换密钥后，写入本机忽略目录中的独立评测配置库并通过最小实际请求；服务经 `MYEVAL_POME_CREDENTIAL_DB` 指定该库恢复。未执行充值或第三方账户变更，不改产品原设置和儿童资料，不将密钥放入代码、日志、UI、报告或 Git。

79 个原 trial 各追加一次执行，保留首次失败，共 271 attempt；源码、case/config 哈希与量表不变。失败补跑不是新样本。共有 851 次模型请求，772 条模型响应用量，79 条拒绝请求用量未知；已知总用量 1,061,764 tokens，不能将缺失当零。当前成功尝试共 771 次模型请求，包含 3 次内部空白输出聊天重试（新 A 1、新 C 2），均恢复；保留的历史失败另有 80 次聊天请求。请求模型与响应型号均为 `deepseek-flash`；chat enabled/low、summary disabled 是请求值，供应商未回显有效 thinking/effort，TTFT 与金额未知。

性能保留 all attempts 与 current attempt 两层；比较工作量采用当前完整执行，同组配对另剔除账户阶段不同的 1 对。旧 C/新 C 的“不需建议”第 1 次采样跨账户，其余 95 对同阶段。缓存、远端时段和账户变化仍限制因果归因。实际历史高价值目标在 3 个有目标的家族共 48/48 当前首轮上下文中出现，这只证明注入，不能代替自然使用评分。

192 个当前隔离数据库均已只读核验：故事和日记与交付相同、草稿已清理、设置库为空。当前 192 次整理请求均只含本次儿童来源，逐字/ID/hash 核对匹配；79 个历史失败没有整理请求，单列 unavailable，不算完整链路通过。请求结构与来源哈希核对不证明语义正确。旧 A/C 文件、默认应用模块及两个用户文档与进入本轮时哈希相同。

## 质量结论

以下胜负按后者相对前者计，只计两位独立评阅的共同偏好；不合总分，不作显著性或因果结论。

| 比较 | 共同胜 / 负 / 平 / 分歧 | 旧回归胜 / 负 / 平 / 分歧 | 新情境胜 / 负 / 平 / 分歧 |
| --- | --- | --- | --- |
| 旧 A → 旧 C | 3 / 14 / 5 / 2 | 1 / 7 / 3 / 1 | 2 / 7 / 2 / 1 |
| 旧 A → 新 A | 11 / 7 / 1 / 5 | 4 / 4 / 0 / 4 | 7 / 3 / 1 / 1 |
| 旧 C → 新 C | 13 / 7 / 3 / 1 | 9 / 1 / 2 / 0 | 4 / 6 / 1 / 1 |

新 C 较旧 C 的具体认可达到 2 分的比例，评阅 A 从 4/20 到 16/20，B 从 1/20 到 17/20；自然交流从 3/24 到 13/24、3/24 到 12/24；情绪陪伴从 12/18 到 17/18、14/20 到 19/20。历史/身份联系两位都仅从 16/18 到 17/18，不能说历史自然结合已解决。所有 192 篇日记两位均评 2，但这是固定合成脚本结果，不能外推长期可靠性。

新 C 主要改善旧回归情境，新情境仍 4 胜 6 负；连续二选一、过多步骤、成人式功劳评价，以及把结束聊天误作停止绘画仍出现。新 A 的具体认可和交流价值有收益，但回应当前需要与现实边界有退步。一例将讲述结束误读为已与同伴约妥，两位与主脑均确认重大问题；另一例无据限制盒内动物身份，major/minor 有合理替代读法，主脑保留严重程度争议。新 C 未有确定 major，不代表没有局部问题。温柔配音、影子伙伴、拟人化的美好画面按语境允许，不机械按未逐字来源扣分。

12 段内部校准短对话、50 项规范目标，两位初评均 50/50 符合；不是教师金标。校准中 7 个引用/时序定位问题修正并保留原件，不调整分数。正式 3411 条交付引文与 3411 条当时来源引文定位无未解决问题。主脑复核 26 个必审及 6 个额外正反例，共 32 个 trial；原独立评分不覆盖。正式量表仍有 16 个情绪适用性、8 个延伸适用性分歧，下一轮需要补充共同游戏和轻量意义解释的校准锚点，本轮不回改量表。96 对中有 15 对偏好分歧，逐项保留。

建议保留新 C 为下一轮教师逐例评阅的主要候选；新 A 保留为用量较低的对照。两者都还不宜根据本次小样本直接替换产品默认。质量按冻结计划保留 24 对；旧 C/新 C 剔除唯一跨账户阶段配对后为 12 胜 / 7 负 / 3 平 / 1 分歧（23 对），结论仍需保持克制。
