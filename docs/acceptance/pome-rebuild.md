# pome 核心体验重建与性能对比

2026-11-11。用户要求推翻每轮短、忠实复述、固定鼓励与完整审校的共同前提；本轮重新实现三套真实产品 profile。没有切换普通产品默认。

## 实现

- **自然陪聊** `direct-companion-v3`：一次生成，以交流价值和少量完整虚构示例引导；可回答知识、提出建议、开放理解、延续孩子开启的想象。
- **理解卡再表达** `perspective-then-speak-v3`：有限的交流目的、重点、原话证据卡，再生成回应。卡片可校验结构与引用，不能保证语义正确。
- **只修明确问题** `selective-repair-v3`：自由生成后检查；无问题原样接受，有明确事实、纠正、停止、安全问题才提交有限精确修补。检查本身仍需第二次模型调用。

三套共用按本次儿童话语从允许历史中选择最多三条的路径；不先截最近三条。动物背景限名字、类型。日记整理只接收本次儿童原话。三套主比较是完整 Agent 对照，不能归因于单句提示词；另设自然陪聊的 off/low 对照。

适配器 `pome-http-5` 共用真实 Handler；MyEval 新增通用逐请求/阶段/执行耗时、调用、重试、用量与缺失统计，UI 和导出均可读。模型请求参数、回显模型及未知的实际生效参数分别记录，不保存隐藏推理内容。

## 冻结与评分

18 个虚构案例，16 个情境家族：6 旧回归、12 独立编写的新例；每配置两次。四组各 36 对，共 **288 trial，273 成功、15 失败**。16 次独立 smoke 不进入正式分母。全部失败均来自本轮基线，未重跑替换；候选和思考消融共 180/180 完成。

六维 0/1/2 分开报告，无总分：回应需要、温度与有据理解、背景使用、自然有用、聊天事实边界、日记来源。取消句数、品质词和逐轮鼓励配额；失败记 unavailable、配对 unable。材料实际注入与当轮已发生原话是证据，不以未来脚本补来源。

每条两份独立匿名内部 AI 评价，共 **576 份**。13 条主脑规范锚点、28 目标校准；锚点并非教师标签。B pass 后段由第三个独立 worker 接续不重叠批次，事先通过同样校准；每对仍只有 A/B 两份，不互读结果。该执行分工变更单独留档。1,568 条引文与 1,303 条来源引文定位/时序检查无缺口；主脑复核全部 14 条重大指控涉及的 trial 与另 2 条两级分歧，原评分不覆盖。真人教师评价 **0**。

## 结果

“胜/负/平”仅计两位共同偏好；分歧和失败另列。每组 36 对，重复不增加家族数。

| 候选对基线 | 共同胜 / 负 / 平 | 分歧 / 无法判断 | 候选成功 | 成功接话 p50 / p95 |
|---|---:|---:|---:|---:|
| 自然陪聊 low | 12 / 5 / 8 | 6 / 5 | 36/36 | 3.40 / 5.75 s |
| 理解卡 low | 7 / 11 / 2 | 10 / 6 | 36/36 | 5.85 / 9.78 s |
| 局部修补 low | 10 / 14 / 1 | 7 / 4 | 36/36 | 6.33 / 10.86 s |

对应基线接话 p50 分别 6.72 / 6.62 / 6.62 s，完整成功执行分别 31/36、30/36、32/36。相同实际儿童文本、两侧均成功的配对中，自然陪聊执行时长比中位数为基线 0.557 倍，用量为 0.754 倍。理解卡和局部修补的用量比分别 1.263、1.274，未获得稳定质量优势。

自然陪聊在回应需要、相关背景有局部收益，但两份评阅对自然有用的 2 分仅 8/36、13/36；事实边界也有下降配对。主脑确认主比较三个候选分别 1、2、2 条重大事实问题；基线另有 1 条日记主体颠倒。不能称全面提升或达到教师验收。

思考消融：low 对 off 共同偏好 **16 / 2 / 6**，分歧 12，均 36/36 完成；接话 p50 / p95 为 low **3.36 / 6.57 s**、off **1.41 / 2.15 s**。该组 off 确认 3 条重大主体/身份问题，low 为 0；小样本不证明风险率。更快的 off 暂不作为优先方向。

本轮最值得继续打磨的是自然陪聊 low；理解卡、局部修补暂不扩大。新流程改善交付完成率和背景机会，重复解释、结束后的多余建议、未经确认的事实归属仍待处理。历史第五条目标在该单例新流程 10/10 次首轮实际可见，基线 0/6；这只证明该例检索改善。

## 性能与验收范围

真实记录 1,677 次模型请求、69 次内部重试，2,305,941 已知 total tokens；失败执行包含 77,107 tokens。基础输入/输出/总用量齐全，推理 token 等未回显值保持未知。请求 deepseek-flash；主比较 chat enabled/low、summary disabled。供应商未直接回显实际生效的 thinking/effort，不将请求声明当作生效证明。

聊天耗时从 HTTP 发出到完整响应读取/解析，包含内部阶段与重试；完整执行另含启动、保存、清理。nearest-rank 分位由原始样本合并重算，失败和缺失不移除。并发固定 2；未测 TTFT、设备渲染、ASR/TTS、首句声音或金额成本。

真实验收：288 次来源指纹与输入状态完整性匹配；180 次新流程日记请求仅含实际 child_sources；288 个隔离 SQLite 读回，273 条成功记录与交付逐字一致、草稿清理正确，设置中无凭据。禁止背景标记无命中，全部 288 trace 已同步平台。8 份最终 JSON/ZIP 包含 576 条评价、864 份附件，CRC、附件 hash、JSON/ZIP 对照通过。实际 UI 下载单份 48 trial / 96 评价包通过，浏览器无告警/错误。

全部任务终态后真实停启服务；29 个历史实验、634 trial 留存，本轮 288 trial、576 评价、匿名映射与性能逐项 hash 不变。源文件语法、源代码 diff 检查及产品补丁反向应用检查通过；嵌套 patch 的空白上下文行不作为源码尾空格错误处理。评分表长标题拥挤在 UI 验收中修复，仅展示变化，冻结执行源码未改。
