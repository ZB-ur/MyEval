# V2.0.0 集成与发布验收

2026-11-25。本次将 V2 核心、用户已确认的界面、项目适配器、任务包和评分规则整合为同一版本，并增加可以独立运行的演示、图文 README 与操作指南。本次没有重跑三项目模型评测，也不改变其历史质量结论。

## 交付内容

- 完整的执行、数据、独立评分、比较、判定、导出与恢复模块，统一版本号为 `2.0.0`。
- 当前界面基线及桌面、匿名评阅、390px 手机宽度截图；只为新增演示项目补充中文名称，保留已确认的视觉设计。
- `scripts/demo.py`、演示适配器及六个虚构办公案例。通过普通 HTTP、runner 和 worker 执行，返回任务包内预编写回复，不调用模型。
- 可移植的启动说明、适配契约、当前状态、贡献说明与第三方声明。去除当前源码中的个人绝对路径默认值；产品目录仍可由环境变量覆盖。
- 当前界面的三段操作参考与十二个关键帧；历史交付资料单独保留。

## 实际验证

环境为 macOS、Python 3.14.3、Chromium 159。核心 Python 文件另通过 Python 3.11 语法兼容检查；这不等同在 Python 3.11 上完成运行验收。

| 来源与规则 | 案例、配置、适配器和任务包哈希冻结；来源改变后的重试被拦截，未调用业务模型；不把未知用量、费用或缺失质量分填成零 |
| 桌面连续操作 | 从首页进入比较、切换成功率、对照候选正文、追踪失败阶段、返回筛选与下载 ZIP；记录期间没有页面脚本异常 |

## 发布边界

仓库仅纳入源码、明确虚构的任务包、量表、文字记录和演示配图。实际模型输出、产品数据库、访问码、提供者凭据、原始录音、模型权重与历史录像不发布。发布前检查了当前文件与可达 Git 历史，没有检出高置信凭据或私钥；只推送指定分支，不推送本地检查点 refs。

三项目适配器需要外部产品 checkout 与各自运行环境；旧 `integrations/` 补丁不构成完整 V2 产品安装包。当前服务仍仅监听本机，没有生产部署、团队权限或远程访问验收。

当前 UI 的用户保留决定与功能验收已确认；旧界面评分不转移为本版的独立盲审分数。浏览器模拟手机宽度不代表物理设备，模型判断不代表真实用户偏好。三项目原评测边界见 [2026-11-18 验收](2026-11-18-platform-v2.md)。
