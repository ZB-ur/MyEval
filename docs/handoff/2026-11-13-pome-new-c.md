# 新 A/C 方案记录与新 C 产品落地

2026-11-13。用户明确选择：记录本轮新 A/C，由 pomegranagent-v2 项目中的独立可见会话实施新 C，模型指定 `gpt-6-astra`、推理 `max`；MyEval 主会话负责复核与实际产品验收。此授权允许将新 C 接为产品默认，不代表教师已逐例验收全部回复。

## 保留的两套方案

共同定位是愿意倾听幼儿、参与分享并给出温暖反馈的日记本朋友。减少无价值复述，让具体欣赏融入对话；允许贴合情境的拟人化、美好想象与延伸，不要求每句加“也许”。明确纠正、现实人物动作、未完成打算和健康安全仍需分清。聊天可以有想象，独立日记只能整理儿童本次原话。

| 方案 | 冻结标识 | 实现区别 | 取舍 |
| --- | --- | --- | --- |
| 新 A：参与式直接回应 | `warm-participant-v5` / `5.0.1` | 共同原则加两段固定原创示范；一次生成直接回应当前最值得接住的一点 | 用量较低，保留作对照；曾将“讲好了”误作已与同伴约妥 |
| 新 C：语境借鉴示范 | `reference-companion-v5` / `5.0.1` | 每次提供完整八段原创虚构多轮参考，模型结合完整对话自行借鉴；移除关键词预筛选 | 具体认可、情绪和朋友感更接近用户选择；参考库增加输入用量，仍可能给过多建议或机械追问 |

两者共用 `relevant-same-child-v3` 历史选择、动物档案、应用控制、JSON 输出与独立整理。新 C 的参考覆盖关心、共享乐趣、受挫、矛盾情绪、知识与比喻、不明对象、历史延续和想象中的现实边界。注入的参考可观测，模型实际借鉴哪条不可观测。所有示范为开发者原创虚构材料，不是教师金标或当前儿童经历。

准确提示词、八段示范与版本位于 pome 的 `backend/friend_profiles_v5.py`；历史构建和上下文路径位于 `backend/dialogue_v3.py`，注册位于 `backend/agent_profiles.py`。以本轮冻结源码和元数据为准，不从过时的固定动物模板重建。

新 C 相对旧 C 的共同偏好为 13 胜、7 负、3 平、1 分歧；其中新情境只有 4 胜、6 负，不能声称泛化问题已解决。新 C 相对新 A 为 8 胜、5 负、4 平、7 分歧。新 C 较旧 C 的具体鼓励、情绪共鸣和交流价值提升较明显，历史自然结合仅小幅提升。用户选择新 C 的产品风格，是此次落地的直接决策依据。

## 最终落地与主会话验收

新 C 已接为普通产品默认。最终产品改动只有 `backend/agent_profiles.py`、`backend/app.py`、`README.md`、`docs/product.md` 四个文件；进入本轮的其余 176 个源码/资源文件哈希未变。新 A/C 提示词、v4 提示词、八段参考库及历史选择模块与原评测冻结文件逐字一致。旧 baseline 仅改名称和说明以标明回退用途，提示词不变。新增结束控制位于应用层，不属于 5.0.1 的冻结提示词。

明确结束控制按完整末句/末尾分句识别，允许结束后继续有限的绘画、涂色、积木或手工活动，以及同一活动完成后再分享；不把任意“再告诉你”、引用或否定当作结束。未覆盖表达仍由模型判断，不能声称通用意图理解已解决。初次 13 例中 12 例符合，扩展固定 17 例首轮为 16 例符合；修复后固定 17 例全部符合：6 个结束样例实际请求前禁问、最终收尾，11 个否定、引用、活动完成或继续讲述样例未被误关。三批执行共 47 次，独立表达仍是 17 个，原失败样本全部保留。
