## 源码与运行资料分开

仓库可独立启动演示和空工作区。真实项目评测需要对应的产品 checkout、共享接口、模型运行环境及已授权凭据。`integrations/` 是历史补丁记录，不是完整产品安装包。

本地使用者的旧数据仍在各自数据目录；新演示使用 `.local/demo/`。原交付包 `.local/delivery/20261118/` 与 V2.0.0 的 `.local/delivery/20261125/` 保留；开源版的本机交付入口为 `.local/delivery/20261125-open-source/README.md`。这些目录不整体随 GitHub 分发，文档中的本机证据路径只供原工作区持有者查阅。

源码更新会影响后续来源校验。旧实验可继续审阅与导出；若待执行配置来源已变，应建立新实验，不能绕过漂移检查或覆写原冻结快照。
