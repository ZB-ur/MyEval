# MyEval 完整评测工作台建设

2026-11-18。用户已授权持续建设、三项目多方案真实评测、UI/UX 独立盲审、操作录屏与 playbook。建设预算不设上限；实际并发、模型、权限和设备以运行环境为准。本文是本轮执行与验收入口，不把计划当作已实现。

## 交付目标

1. 共享闭环：版本化任务集与开发/留出划分、多配置实验、独立评分作业与历史重评、家族级比较及不确定性、可解释发布判定、机器可用 CLI、恢复与证据导出。
2. 交互与环境：脚本/动态多轮、跨 episode 状态与工具环境的明确契约；真实媒体证据接入。已实现能力与未接入能力在 UI 明示。
3. 运行与治理：本机优先，授权数据接入与溯源、评审分工、预算/并发/超时、线上轨迹导入和回流、备份恢复。外部部署、付费、生产流量接入不是默认动作。
4. 体验：中文信息架构、清晰空态与错误态、快捷筛选、长结果对照、逐步建立实验、任务与证据导航；不以营销词、总分或装饰图表遮蔽未知。
5. 三项目：pomev2、Sijian、Sidelit 各冻结当前真实基线，至少两个具有明确行为假设的候选；开发筛选后冻结，再对独立留出情境评测。正/负结果、失败和重试全部保留。经验证有改进的候选可交付为可切换版本，未获默认切换授权时不改产品默认。
6. 参考手册：所有本轮浏览器操作旅程连续录屏，阶段索引、关键帧、实际步骤、输入与预期结果构成 playbook。后台实施保留命令/版本/日志与验收记录。凭据和私人数据不进入视频。

## 边界与保护

当前 MyEval 既有未提交工作已保存在 `.local/coordination/20261118/source-before/`，文件 hash 在同级 baseline-manifest.json。所有会话按文件所有权并行，不回滚他人改动。旧数据目录只用于只读复核；新版先使用独立 `.local/v2/data` 和端口 8320。模型请求材料默认明确合成，真实材料需要可追溯授权。

Sijian V13 不变。pome 声音不作为文本策略迭代的变量。Sidelit 不上传私人照片；当前手机不可用，本地模型、Mac、Simulator 与真机证据分开。不新增单元测试、测试目标或断言脚本冒充验收。

## 数据与统计原则

固定 experiment / trial / attempt / evidence / assessment 的现有身份；新能力向后兼容。配置与评分器版本独立，评价绑定具体 attempt 和输出 hash。多候选支持基线对每候选的匿名配对，不把每次重复或评阅人数算成独立案例。家族级配对统计保留平局、无法判断、失败和分歧；描述性结果与统计推断分开。内部 AI 规范校准不冒充教师/用户金标。

新候选在读取留出材料前冻结；候选实现方不编辑留出集。发现泛化失败后可新开开发轮次，但不得重写旧结果或把已看过的案例继续称为留出。UI 盲审评阅者不接收作者、目标评分或他人的意见。

## 协作与证据

内部子智能体用于短时审计和独立复核；侧栏可见子会话承担长程独立实现。主脑负责契约、整合、主浏览器和最终判断。当前内部并发工具上限为 4，按实际容量安排，无虚报无限并发。会话信息、运行 ID、关键决定记录在本机 `.local/coordination/20261118/`；产品源码、依赖变动和接口文档进入正常仓库，实际输出/录像/凭据只留忽略目录。
