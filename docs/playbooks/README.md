## 三种材料，不混用结论

**办公演示**随源码分发，任何读者都能运行。它说明平台的操作和证据流，不能证明某个 AI 方案更好。

**公开任务包**包含合成文本或公开图片的来源引用。真实产品适配器仍需要对应产品代码、模型环境和授权；克隆本仓库不会同时安装三个产品。

**历史项目评测**在案例中展示方法、聚合结果和限制。原始私有运行、正式留出材料与模型输出没有公开；读者可复用方法，但不能仅凭公开包逐条复现这些历史数值。

另有[离线录像包](https://github.com/ZB-ur/MyEval/releases/download/v2.0.1/MyEval-v2.0.1-playbook.zip)：5 段虚构演示原片、23 个章节和关键帧，解压后打开 `playbook.html`。录制范围和未录制间隔在包内明确标注。
