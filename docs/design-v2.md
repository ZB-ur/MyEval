# MyEval 工作台设计

2026-11-18。本轮前端由 `web/` 的原生 HTML/CSS/JavaScript 实现；无远程字体、无构建依赖。三轮独立盲审 A/B、C/D、E/F 的原始评分与证据保留。第四轮 UI 已完成实际浏览器验收并冻结源码，由主会话组织新评阅者独立盲审；功能验收和源码审阅均不替代盲审评分。

## 页面围绕要完成的事组织

工作区首页回答“现在进行到哪、下一步做什么”。实验列表负责查找；实验详情以“比较、运行、评分、评审、来源”分区。长输出有独立对照阅读入口，阶段证据与配置快照放在需要追查时容易找到的位置。规则、模型、人工与运行事实保留独立名称和分母。

新建实验分为材料、方案、执行设置、核对建立四步。基线唯一，候选可以多个；规模随案例、方案与重复改变。最终页展示实际请求规模、数据来源与启动行为，支持先建立再调度。开发与留出分组由数据版本提供，不能以 UI 标签代替独立性。

数据集呈现不可变版本、来源、授权和家族数；评分作业呈现独立状态、失败与历史结果绑定；运行管理呈现队列、暂停/恢复和备份。接口不可用时展示可定位原因，不能填入示例数字。

## 视觉与可读性

采用温和的灰白画布、清楚的表面边界、深墨色文字与单一松绿色强调。宽屏固定侧栏，内容保留足够呼吸；主要数字用等宽数字，复杂状态以文字和颜色共同表达。表格把标题、状态、进度和规模放在同一阅读线上，少用巨大的指标卡。

标题、正文、辅助说明分层；中文长文使用较宽行距，原话保留换行。配置参数与 hash 默认折叠，避免技术信息占据主要操作区。窄屏变为可展开导航、方案与质量卡片；复杂原始证据表仍可横向滚动；所有主要动作具备键盘焦点和可访问名称。

参考了主会话已检视的 Mobbin [Braintrust 实验表与轨迹](https://mobbin.com/screens/bb7a5740-36c6-4740-babf-05f053e5d8d2) 与 [Amplitude 概览](https://mobbin.com/screens/085abd33-4b85-41d8-a7d8-60d7f08cee12)，用于信息密度和导航层次研究。

## 可靠交互

路由切换立即取消前一页的读取；只有当前请求可以提交页面。自动刷新不覆盖表单、选择与正在阅读的展开内容；列表通过明确刷新更新，运行中的页面显示可用更新提醒。请求出错时保留路径、重试入口和错误信息。

匿名评审使用单独页面，不请求配置映射或性能数据。只有提交当前配对评价后，评审者主动操作才揭示身份。功能验收试填与真实人工判断分开。

## 验收关注点

1. 有慢请求和轮询时仍能连续切换页面，不出现地址已切换而内容滞留。
2. 多候选实验从选择到核对、暂停建立、恢复运行、异常定位与导出可用。
3. 真实评分/重评、数据导入、判定和备份接口的成功与失败均有反馈。
4. 长内容对照、匿名评价保存、窄屏和键盘操作不丢上下文。
5. 视觉与易用性由独立评阅者实际盲审，保留未达标轮次与问题。
